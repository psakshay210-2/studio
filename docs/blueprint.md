# **App Name**: EventFlow

## Core Features:

- Role-Based Access: Enable different views and permissions based on user roles such as Organizer, Approver, Participant, Vendor, and Sponsor.
- Event Creation Wizard: Guide organizers through a step-by-step process to input event details, set up teams, create schedules, and manage resources. Forms and validation will use standard HTML practices for maximum compatibility and future-proofing.
- Personalized Dashboards: Each role will get a customized dashboard displaying relevant information, such as upcoming events, tasks, approval requests, or sponsorship opportunities. LLM tool evaluates context to make best choice of visible data elements.
- Real-Time Communication: Facilitate communication between organizers, team members, and vendors through a messaging system with dedicated channels for each event.
- Interactive Kanban Board: Enable event organizers and team members to visually manage tasks using a Kanban board with drag-and-drop functionality.
- Mobile-Friendly Interface: Ensure the application is accessible and functional on various devices, providing a seamless user experience on both desktop and mobile.

## Style Guidelines:

- Primary color: Deep indigo (#4F3674) to convey professionalism and sophistication.
- Background color: Soft lavender (#E6E6FA) to provide a gentle, uncluttered backdrop.
- Accent color: Vibrant magenta (#E0077D) to highlight key actions and interactive elements.
- Headline font: 'Poppins', a geometric sans-serif for a modern and fashionable look. Body font: 'Poppins', use same font as headline for visual consistency.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use a consistent set of modern, minimalist SVG icons throughout the app to ensure a clean and professional look.
- Implement a card-based layout for displaying event information, tasks, and vendor requests to maintain a structured and visually appealing design.
